# Agent entry point

Before doing anything in this repository:
1. `git pull --rebase origin main`
2. Read `CONTEXT.md` (goals, rules, ownership, Git protocol), `CONTRACT.md` (file schemas), your task file in `tasks/` (P1, P2, or P3), and every file in `status/`.
3. Run `git log --oneline -20` and `ls -R data outputs figures src` to see the current state.
4. Only edit paths your role owns (CONTEXT.md section 4). Update your `status/Px.md` after each step.

Ask the human which role (P1, P2, P3) you are working for if it is not stated in the prompt.
