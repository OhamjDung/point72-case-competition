## Step 4 prompt: aggregation

```
Role: P2. Follow CLAUDE.md and CONTEXT.md first.

Write src/aggregate.py. Inputs: data/clean/items.csv, data/labels/item_features.csv, data/fundamentals/dks_quarters.csv. Output: data/indices/quarterly_index.csv per CONTRACT.md. Support --mock and --strict.

Pre-registered method (implement exactly):
1. Fiscal quarters from period_start/period_end in dks_quarters.csv. Never calendar quarters.
2. Allocate each item's weight across fiscal quarters in proportion to the overlap of [date_low, date_high] with each quarter. --strict drops items whose interval spans a quarter boundary.
3. w_i = p_relevant x allocation share.
4. Per fiscal quarter and banner (argmax of p_banner_*, plus an "all" row):
   intent_idx = weighted mean of (p_intent_up - p_intent_down), weight w_i x p_author_customer
   stockout_idx = weighted mean of p_stockout
   promo_idx = weighted mean of promo_score_exp
   stars_idx = weighted mean of stars where present (weight = allocation share only; the non-Laya baseline)
   volume_log = log(1 + n_effective), kept separate
5. If n_effective < 15, indices are NaN. Missing is never neutral.
6. X_shock_q = X_idx_q - mean of available X_idx over q-1..q-4; need at least 2 prior non-missing quarters, else NaN.
7. FY2026Q3: partial = True; coverage_frac = days of data within the quarter / quarter length.
Print n_items and n_effective per quarter per banner; warn below threshold. Test on MOCK_ files first.
```

## Step 5 prompt: backtest and nowcast (pre-registered)

```
Role: P2. Follow CLAUDE.md and CONTEXT.md first.

Write src/backtest.py. Inputs: data/indices/quarterly_index.csv (banner "all"), data/fundamentals/dks_quarters.csv. Outputs: outputs/backtest.csv, outputs/nowcast.json, outputs/leadlag.csv, outputs/metrics.csv per CONTRACT.md. Support --mock.

Pre-registered spec (implement exactly; no extra variants):
Target: comp_pct. Primary signal: intent_shock. Secondary: stockout_shock. Comparison: stars_shock. The quarter-q signal uses only items dated inside quarter q (available before report_date).
Models:
  persist: comp_{q-1}
  ar: OLS comp_q = a + r*comp_{q-1}
  ar_laya: OLS comp_q = a + r*comp_{q-1} + b*intent_shock_q
  ar_stars: same with stars_shock_q (skip if unavailable)
  secondary: ar_laya with stockout_shock, reported separately
Validation: expanding window; first training window = first 6 quarters with non-missing signal; forecast next quarter; refit; repeat. Any standardization is fit inside each training window only.
metrics.csv: MAE and RMSE in bp per model, number of OOS quarters, count of quarters where ar_laya beats ar. No p-value searching.
leadlag.csv: correlations of intent_idx and stockout_idx with comp at leads/lags -1, 0, +1, with n.
Nowcast: fit ar_laya on all completed quarters; predict FY2026Q3 with its partial-quarter shock. delta_comp_bp = (pred_ar_laya - pred_ar) * 100, with an 80% interval from the coefficient standard error. verdict = "nowcast" if the 80% interval for b excludes zero AND ar_laya OOS MAE < ar OOS MAE, else "scenario".
Print a plain-English summary, including the scenario case. Test on MOCK_ first.
```
